# Версии редизайна KOREANA

Снапшоты разных итераций сайта. Каждая папка — полностью самодостаточная копия (`index.html`, `css/`, `js/`, `assets/`), её можно открыть в браузере отдельно.

## Итерации

### v1-baseline
**Дата:** апрель 2026

Первая полная переделка сайта со старого koreana.info. Что было:
- Новый одностраничник с современным дизайном
- Палитра: тёмно-синий (`#1a1a2e`) + коралловый (`#d4776b`)
- Шрифты: Manrope + Inter
- Секции: Hero, About, Stats, Why us, Brands (фильтр по категориям), Partners (5 крупных + 16 мелких), Form, Vacancies, Map, Footer
- Текстовые карточки брендов (без фото продуктов)
- Логотип компании оставлен оригинальный (тории + KOREANA)

Скриншоты v1 — в `v1-baseline/screenshots-v1/`.

---

### v2-current
**Дата:** май 2026 (снапшот перед v3)

Финальная версия v2 — заархивирована перед разработкой v3. Это то, что было в корне до мая 2026.

Что было:
- Новая палитра: красный (`#E30613`) + чёрный (`#0a0a0a`) + белый — фирменные цвета
- Hero с летающими логотипами брендов вокруг названия KOREANA
- Новая секция "История компании" (timeline 2015 → 2026)
- Новая секция "Миссия и ценности" (6 icon-cards)
- Бренды переделаны в визуально-богатые карточки с реальными лого и фото продуктов
- Партнёры разделены на "Клиенты (розница)" / "Поставщики"
- Новая секция "Где купить" — маркетплейсы (Kaspi, WB, Ozon, Halyk, Airba) + офлайн-сети
- Форма переименована в "Стать клиентом", добавлен выбор канала связи

---

### v3-cinematic ← **текущий корень сайта**
**Дата:** май 2026

Новое направление дизайна — кинематографичный hero. Остальные секции идентичны v2.

Изменения (только hero):
- Полноэкранный `<video>` на фоне (autoplay, muted, loop) — добавить свой URL в `index.html`
- Анимированный CSS-градиент как fallback (работает без видео)
- Текст выровнен по левому краю, набор крупным шрифтом Manrope
- Заголовок: `clamp(64px → 136px)`, вес 800, трекинг −4px
- Одна основная CTA + текстовая ссылка
- Тёмный overlay с угловым градиентом для читаемости

Чтобы добавить видео: открой `versions/v3-cinematic/index.html` (или корневой `index.html`), найди `<source src="">` и замени пустую строку на URL .mp4 (например с pexels.com/videos или mixkit.co).

---

### v3-magazine
**Дата:** май 2026

Альтернативное направление — редакционный split-screen hero (для сравнения с v3-cinematic).

Изменения (только hero):
- Два панели: левая (кремовый фон `#f4ede3`, тёмный текст) + правая (видео / анимированный градиент)
- Шрифт заголовка: Playfair Display (serif) — editorial-feel
- Статы: 9 лет / 450+ SKU / 16 городов
- Декоративный бейдж с логотипом бренда в правом нижнем углу медиа-панели
- Адаптив: на мобайле панели стекуются (текст сверху, медиа снизу)

Чтобы сравнить с cinematic: открой `versions/v3-magazine/index.html` рядом с `versions/v3-cinematic/index.html`.
