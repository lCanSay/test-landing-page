# Версии редизайна KOREANA

Снапшоты разных итераций сайта. Каждая папка — полностью самодостаточная копия (`index.html`, `css/`, `js/`, `assets/`), её можно открыть в браузере отдельно.

## Итерации

### v1-baseline
**Дата:** апрель 2026

Первая полная переделка сайта со старого koreana.info. Что было:
- Новый одностраничник с современным дизайном
- Палитра: тёмно-синий (`#1a1a2e`) + коралловый (`#d4776b`)
- Шрифты: Manrope + Inter
- Секции: Hero, About, Stats, Why us, Brands (фильтр по категориям), Partners (5 крупных + 16 мелких), Form, Vacancies, Map, Footer
- Текстовые карточки брендов (без фото продуктов)
- Логотип компании оставлен оригинальный (тории + KOREANA)

Скриншоты v1 — в `v1-baseline/screenshots-v1/`.

### v2 (в работе)
**Дата:** TBD
